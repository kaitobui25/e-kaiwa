# STT samples

`run_stt_test.bat` downloads five **real Japanese-speaker English** WAV samples into this folder on the first run, then pads/trims each file to 5 seconds for a consistent STT smoke test.

Source: `Nexdata-AI/207-Hours-Japanese-Speaking-English-Speech-Data-by-Mobile-Phone` on GitHub.

The source repository labels its dataset licensing as **Commercial License**. These clips are downloaded directly from the source for local evaluation; this repository does not re-host them. Do not bundle or redistribute them with the app without confirming the source license/permission.

Generated local files are ignored by Git.
