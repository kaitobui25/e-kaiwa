# Icons

Source: Lucide (`lucide-icons/lucide`, main branch).

Included:
- mic.svg
- settings.svg
- x.svg
- chevron-down.svg
- volume-2.svg
- rotate-ccw.svg
- info.svg

All use:
- 24x24 viewBox
- `fill="none"`
- `stroke="currentColor"`
- stroke width 2

Prefer inline SVG when icon color/state changes with CSS.
If the app already has an equivalent icon, reuse the existing one instead of
introducing duplicate assets.
